# Root SSH только по ключу

`00-root-key-only.conf` устанавливается как `/etc/ssh/sshd_config.d/00-root-key-only.conf`.
Он запрещает парольную и keyboard-interactive-аутентификацию только для root, сохраняя
вход по ключу. Общий PasswordAuthentication и Match-правила других пользователей не меняются.

Перед установкой проверить первое действующее Include, порядок конфигурации и эффективные
настройки `sshd -T -C` для реального пользователя/источника. Сначала подтвердить независимый
вход по publickey с отключёнными паролями и сохранить уже открытое соединение.
Сделать закрытую резервную копию `/etc/ssh` и проверить соседние службы.

Шаблон доставляется через git. На sparse-копии шлюза его можно получить из объекта коммита
командой `git show HEAD:deploy/ssh/00-root-key-only.conf` в закрытый рабочий файл вне репозитория;
расширять sparse-checkout или копировать приложение другим транспортом не требуется.

Перед reload запланировать независимый от SSH автоматический откат: при срабатывании он
должен переместить только созданный drop-in в резервную копию, выполнить `sshd -t` и reload ssh.
Убедиться, что откат не затрагивает конфигурацию, созданную кем-либо ещё. Проверить этот путь
восстановления, затем повторно применить drop-in с заново запланированным откатом.

После `sshd -t` выполнить reload, затем открыть новое соединение без ControlMaster,
разрешая только publickey. Проверить эффективный PermitRootLogin (prohibit-password или
его синоним without-password), доступ остальных пользователей и прежние ограничения ключа шлюза.
Только после успешного нового входа и проверок остановить таймер отката и закрыть
страховочное соединение. Перезапуск sshd, изменение паролей, показ ключей и попытки
подбора пароля для этой проверки не требуются.

Консоль провайдера — отдельный способ восстановления; доступ к ней не следует считать
проверенным только по наличию SSH-ключа или резервной копии. В этой процедуре проверяется
восстановление действующей конфигурации независимым заданием systemd при сохранённой SSH-сессии.

[Значение PermitRootLogin в документации OpenSSH](https://man.openbsd.org/sshd_config#PermitRootLogin).
