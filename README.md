# pg16-cert-prep

Веб-тренажёр для подготовки к сертификации по PostgreSQL 16 на основе курса DBA1.

257 вопросов по 16 темам курса: тренировка по темам, экзамен с таймером и разбором ошибок, работа над ошибками.

## Возможности

- **Тренировка по темам.** 16 категорий в порядке курса (01–16), вопросы и варианты ответов перемешиваются. После ответа сразу видны верный ответ и пояснение.
- **Три формата вопросов.**
  - один правильный ответ из четырёх;
  - несколько правильных ответов (подсказка «выберите один или более»), засчитывается только полное совпадение;
  - «дополните код»: фрагмент с пропуском `___` и четыре варианта вставки.
- **Экзамен.** 20, 30 или 50 случайных вопросов из выбранных тем, таймер (1,5 минуты на вопрос), возврат к предыдущим вопросам, порог сдачи 70%. В конце процент, результат по темам и разбор ошибок с пояснениями.
- **Работа над ошибками.** Журнал ответов: вопрос попадает в список, если последний ответ на него был неверным, и уходит из него после верного.
- **История экзаменов.** Дата, результат, «Сдан» или «Не сдан» и затраченное время для последних 50 экзаменов.
- Светлая и тёмная тема по настройке системы.

Правильные ответы не отдаются браузеру вместе с вопросами: проверка выполняется на сервере.

## Стек

Node.js, Express 5, `pg`, PostgreSQL. Запросы пишутся на нативном SQL без ORM. Страница на чистых HTML, CSS и JS без сборки и зависимостей.

## Требования

- Node.js 18 или новее (проверено на 22).
- PostgreSQL 14 или новее (проверено на 14.7).
- Клиент `psql`.

## Установка

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте базу данных и роль PostgreSQL для приложения (имена выберите сами).

3. Скопируйте шаблон настроек и заполните его. Файл `.env` в репозиторий не попадает.

   ```bash
   cp .env.example .env
   ```

   | Переменная | Назначение |
   |---|---|
   | `PORT` | порт приложения (по умолчанию 3000) |
   | `HOST` | адрес, на котором слушает приложение (необязательно, по умолчанию `127.0.0.1`, то есть только этот компьютер) |
   | `NODE_ENV` | необязательно: при значении `production` отключается `GET /api/test` |
   | `DB_HOST`, `DB_PORT` | адрес и порт PostgreSQL |
   | `DB_NAME`, `DB_USER`, `DB_PASS` | база, роль и пароль |

4. Примените миграции по порядку. Каждую нужно выполнить один раз: миграции 002, 003 и 006 добавляют вопросы и при повторном запуске задублируют их.

   ```bash
   set -a; . ./.env; set +a
   for f in migrations/*.sql; do
     PGPASSWORD="$DB_PASS" psql -h "$DB_HOST" -p "$DB_PORT" -U "$DB_USER" -d "$DB_NAME" -v ON_ERROR_STOP=1 -f "$f"
   done
   ```

   | Миграция | Что делает |
   |---|---|
   | `000_base_schema.sql` | таблицы `categories` и `questions`, пробный вопрос |
   | `001_create_tasks.sql` | таблица `tasks` для учёта хода работы, к самому тренажёру не относится (необязательна) |
   | `002_seed_questions.sql` | 30 вопросов по темам 01–03 |
   | `003_seed_questions_04_16.sql` | 130 вопросов по темам 04–16 |
   | `004_number_categories.sql` | номера тем в названиях категорий |
   | `005_multiple_correct_answers.sql` | поддержка нескольких правильных ответов |
   | `006_seed_multi_and_code.sql` | 96 вопросов «несколько ответов» и «дополните код» |
   | `007_answer_log.sql` | журнал ответов для работы над ошибками |
   | `008_exam_history.sql` | история экзаменов |

5. Запустите сервер и откройте <http://localhost:3000>:

   ```bash
   npm start
   ```

   Для разработки с автоперезапуском: `npm run dev`.

## API

| Метод и путь | Назначение |
|---|---|
| `GET /api/categories` | категории с числом вопросов |
| `GET /api/questions?category_id=` | вопросы категории без ответов |
| `POST /api/answers` | проверка ответа: `{question_id, answer}`, ответ из нескольких букв пишется слитно, например `"AC"` |
| `GET /api/exam?count=&categories=` | случайные вопросы для экзамена без ответов |
| `POST /api/exam/check` | проверка всех ответов экзамена, итог и порог сдачи |
| `GET /api/mistakes` | вопросы, на которые последний ответ был неверным |
| `GET /api/exam/history` | последние 50 завершённых экзаменов |
| `GET /api/test` | проверка соединения с базой (кроме `NODE_ENV=production`) |

## Тесты

```bash
node --test tests/api.test.js
```

Тесты работают с базой из `.env`. Записи, которые они добавляют в журнал ответов, удаляются по окончании, а временные вопросы создаются и удаляются в ходе самих тестов.

## О вопросах и материалах

Вопросы и пояснения написаны своими словами по темам курса DBA1 компании Postgres Professional (© Postgres Professional, 2017–2024). Материалы курса в репозиторий не входят, их можно скачать на <https://edu.postgrespro.ru>.

В текстах вопросов можно использовать блоки кода между тремя обратными кавычками и фрагменты кода в одиночных обратных кавычках.
