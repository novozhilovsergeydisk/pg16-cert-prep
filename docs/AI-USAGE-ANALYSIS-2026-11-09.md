## Особенность штатного отчёта

Подтверждён сдвиг на три часа при сериализации часовых и минутных групп
через Node.js в часовом поясе Europe/Moscow. SQL выражение
`received_at AT TIME ZONE 'UTC'` возвращает timestamp без часового пояса;
драйвер интерпретирует его как местное время, затем JSON сериализует в UTC.
В результате час 16:00 UTC показывается как 13:00Z. Контрольный агрегат
с `to_char` возвращает правильный час 16:00 UTC для всех шести запросов.
Сами timestamptz первого/последнего запроса корректны. Количества, длительности
и токены от сдвига подписей групп не меняются. Код отчёта не исправлялся:
пользователь требует согласовывать изменения кода.
