# ТЗ: тренажёр подготовки к сертификации PostgreSQL 16

Утверждено пользователем 09.10.2026. Всё, чего здесь нет дословно, в реализацию не входит без отдельного согласования.

## Цель

Веб-тренажёр для подготовки к сертификации по PostgreSQL 16 на основе курса DBA1.

## Входит в первую версию

1. Список категорий. Категории соответствуют темам курса DBA1.
2. Режим тренировки: выбрать категорию, получать вопросы по одному, ответить, сразу увидеть верный ответ и пояснение.
3. API:
   - `GET /api/categories`
   - `GET /api/questions?category_id=`
   - `POST /api/answers` (проверка ответа на сервере)
4. Простая страница на чистом HTML и JS.
5. Загрузка вопросов в БД через SQL-миграцию.

## Существующая схема БД

- `categories`: `id`, `name` (уникальное, до 100 символов).
- `questions`: `id`, `category_id` (внешний ключ на `categories`, `ON DELETE CASCADE`), `question_text`, `options` (`jsonb`), `correct_answer` (`char(1)`), `explanation`.

Таблицы принадлежат роли `postgres`. Роли приложения нужны права, они выдаются отдельно по согласованию.

## Технические ограничения

- Нативный SQL через `pg`, без ORM. Запросы параметризованные.
- Нативный PostgreSQL, без Docker.
- Секреты только в `.env`, в вывод и репозиторий не попадают.

## Отложено

- Режим экзамена (случайные N вопросов, таймер, итог в процентах).

## Не согласовано, в версию не входит

- История ответов и статистика.
- Пользователи и авторизация.
- Вопросы с несколькими правильными ответами.
- Языки кроме русского.
