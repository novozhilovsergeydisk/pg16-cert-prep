# Проверка повторов — 14 октября 2026

Я проверил 496 вопросов во всех 17 разделах локальной и серверной базы: буквальное совпадение, совпадение после нормализации регистра/пробелов/пунктуации и смысловые пересечения внутри разделов. Сервер я только читал. Вопросы по итогам этой проверки не изменял и не удалял.

**Результат:** точных нормализованных дублей нет. Я выделил **16 пар в 12 разделах**, которые проверяют практически один и тот же факт, в том числе в формате «теория + допишите команду». Это кандидаты на замену одного вопроса, если цель — избегать повторения одного знания в порции. Смысловая оценка ручная, она не является доказательством отсутствия любых других пересечений.

## Проверка выдачи

Серверный запрос выдачи совпадает с локальным: каждая строка questions выбирается один раз; соединение с последним ответом ограничено LIMIT 1. Перемешивание в браузере также не создаёт копии. Это исключает дублирование одного ID самим текущим запросом, но не исключает семантически близкие вопросы с разными ID и повторные открытия порций.

ID в локальной и серверной базе различаются для большинства дополнительно загруженных вопросов. Я сопоставил их по тексту: содержимое совпадает, кроме четырёх вопросов, исправленных локальной миграцией 027. Ниже приведены оба набора ID; при будущих исправлениях следует искать вопросы по тексту, а не переносить локальные ID на сервер.

Старый журнал не содержит номера порции, порядка показа, снимка текста и признака режима. Поэтому по нему нельзя достоверно отличить повторную отправку, повторное открытие темы и работу над ошибками или доказать, что конкретная пара попала в одни 16 вопросов. Я не включал в отчёт адреса пользователей и полный журнал действий.
