# Исправления по аудиту темы 01 — 14 октября 2026

Я исправил четыре ошибки интерфейса из [аудита](LEARNING-AUDIT-2026-10-14.md) и уточнил четыре вопроса темы 01. Изменения проверены локально; коммит, деплой и применение миграции на сервере я не выполнял.

## Поведение приложения

- **F1 и F3:** я блокирую повторную отправку и изменение выбранных вариантов на время запроса. Результат применяется только к тому экземпляру экрана, с которого его отправили. Запоздалый ответ или ошибка не меняют другой вопрос, включая повторно открытый исходный вопрос. При отказе API можно изменить выбор и повторить отправку.
- **F2:** я сохраняю первоначальный срок экзамена. После неудачного завершения отсчёт возобновляется, если время осталось. После срока ответы блокируются, таймер показывает `00:00`, повторное завершение доступно вручную. Непрерывного цикла запросов к недоступному API нет. Это работает и для сохранённого экзамена, открытого после истечения срока. На время отправки результата варианты и кнопки навигации блокируются.
- **F4:** я разместил счётчик под названием темы на узких экранах. На ширине 320 px ширина документа теперь тоже 320 px, горизонтального переполнения нет.

Основные изменения: [app.js](../public/js/app.js), [style.css](../public/css/style.css). [Скриншот карточек после исправления](audit-2026-10-14/categories-320-fixed.png).
