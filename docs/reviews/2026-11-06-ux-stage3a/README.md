# UX, этап 3а: запуск и обзор экзамена

Задача №187. Локальная версия для просмотра, 6 ноября 2026. Коммита и выпуска ещё нет.

## Изменения

Перед началом экзамена число вопросов, время, количество выбранных тем и кнопка старта находятся сверху. Длинный список тем раскрывается отдельно. Сводка пересчитывается при смене числа вопросов и тем. Если вопросов в выбранных темах меньше выбранного лимита, показано фактически доступное число и соответствующее время. При пустом выборе старт недоступен. Во время загрузки вопросов настройки и кнопка временно блокируются, повторное нажатие не создаёт новую попытку; запоздалый ответ не возвращает пользователя с другого раздела в экзамен.

В экзамене над вопросом находится раскрываемый обзор с количеством отвеченных вопросов и кнопками номеров. Есть четыре визуальных признака:

- заполненная точка — ответ дан;
- тире и пунктирная граница — просмотренный, но оставленный без ответа вопрос;
- пустой кружок — ещё не открытый вопрос;
- отдельная рамка — текущий вопрос, независимо от наличия ответа.

Верность не обозначается до завершения экзамена. Кнопки доступны с клавиатуры и имеют подписи с номером и состоянием; текущая кнопка имеет `aria-current=step`. Статус не передаётся только цветом. Во время отправки экзамена обзор блокируется вместе с остальным управлением. Истёкший таймер блокирует изменение ответов, как и прежде.

Переход по номеру и кнопками «Назад / Далее» сохраняет ответы, открывает нужный вопрос и не изменяет срок окончания. На телефоне обзор после перехода сворачивается, фокус переносится к вопросу, а прокрутка сохраняет видимыми таймер и строку обзора. На компьютере обзор можно оставить раскрытым. Перерисовка таймера не пересоздаёт кнопки и не отнимает фокус.

Ответы, текущий номер и отметки просмотра восстанавливаются после обновления страницы. Старая сохранённая попытка без массива посещений открывается с прежними ответами и сроком: для неё просмотренные позиции определяются приблизительно по текущему номеру и наличию ответов, поскольку точной истории раньше не было.

## Проверки

Прежние **46** браузерных/API-сценариев и **9** новых сценариев экзамена прошли; итого **55** разных проверок интерфейса. Дополнительно повторён уточнённый сценарий расчёта времени при малом количестве вопросов. `git diff --check` без ошибок.

Проверены: старт на первом экране; пересчёт при выборе тем и пустой выбор; доступных вопросов меньше лимита; переход по номерам на телефоне и компьютере; сохранение порядка вариантов, ответов и срока после reload; разные состояния обзора; снятие всех отметок в вопросе с несколькими ответами; Enter с клавиатуры; блокировка при отправке и истёкшем времени; отсутствие повторного запуска; отказ от устаревшего ответа после ухода; карта из 50 вопросов на 320 px; старая попытка без отметок просмотра.

Код сервера, проверка правильности и порог сдачи не менялись. Миграций нет. Изменения — браузерные файлы, тест и команда его запуска. История подробных результатов экзамена и переработка статистики в этот этап не входят.
