# Правила для агентов (Codex и других) в проекте pg16-cert-prep

Сначала прочитать [CLAUDE.md](CLAUDE.md): правила про секреты и порядок работы действуют для всех агентов.

## Выпуск на сервер только через git

Сервер `appuse` (каталог `/var/www/pg16-cert-prep`) — это git-копия репозитория. Обновлять его можно **только** так:

1. коммит в `main`, `git push`;
2. на сервере `git fetch`, посмотреть `git log HEAD..origin/main`, затем `git pull --ff-only`;
3. миграции базы — отдельным шагом, после резервной копии базы; перезапуск службы только если менялся серверный код.

**Запрещено** доставлять файлы на сервер любым другим способом: `scp`, `rsync`, `tar`, `git archive`, правка файлов прямо на сервере. Такой выпуск оставляет рабочую копию на сервере «грязной», ломает `git pull` и скрывает, какая версия там работает.

Если на сервере `git status` показывает изменения или неотслеживаемые файлы, остановиться и сообщить пользователю. Не чистить и не «чинить» самостоятельно.

**Почему:** 14–15.10.2026 изменения (история порций, миграции 027–029) попали на сервер копированием файлов, а коммиты остались неотправленными. Пришлось выравнивать сервер вручную.

## Коммит, push, выпуск и миграции

Только после явного разрешения пользователя в текущей беседе. Разрешение на один шаг не распространяется на другие: «закоммить» не значит «выложи на сервер».

## Перед правкой на сервере

Любая правка на сервере (конфигурация, права, службы) — только после резервной копии изменяемого и проверки соседних сайтов: на сервере работают чужие рабочие сайты.
